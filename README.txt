SAI KRIPA RESTAURANT & SWEETS — WEBSITE STARTER

Files:
- index.html  : website structure and restaurant information
- style.css   : responsive design and styling
- script.js   : mobile navigation and current year

HOW TO RUN:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Before showing/selling it to the owner, verify all details with the restaurant.

IMPORTANT OWNER APPROVAL / CUSTOMIZATION:
- The phone number and address were taken from public business listings. Confirm them with the owner.
- Public listings show hours around 7:00 AM–11:00 PM, but confirm the current schedule.
- The website intentionally uses food categories, not an invented dish-by-dish menu or prices.
- Replace the sample food photos with the restaurant's own approved photos.
- Add the owner's confirmed menu, prices, logo, WhatsApp number, ordering process and social links.
- Confirm whether online ordering / table booking is actually offered before advertising those features.

The website is a static front-end concept. It does not include an admin panel, database, payment gateway or order-management backend.
